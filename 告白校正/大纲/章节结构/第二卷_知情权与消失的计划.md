## 1. 第二卷总览

- **最终章节数量**：15章。
- **选择理由**：15章可用11章完成9月8日至11月8日的本线关系重建、10月18日原作交审及知情权裂缝，再用4章连续加速11月9日。它既不需要重复T1制作与权限冲突，也能让22:25—22:50的决定性场景完整落在一章。
- **章节编号范围**：第18—32章，承接第一卷第17章。
- **总字数**：约3.62万字，落在3.2万—3.8万字范围内。
- **时间范围**：T2的2026年9月8日至11月9日晚；第三次回档发生后，女主抵达T3的9月15日。
- **全卷关系曲线**：女主带着T1关系记忆主动退回搭档边界 → 当前男主在无前线记忆的情况下重新建立默契与好感 → 女主用克制靠近保护关系，又把保护扩大为控制知情时间 → 返还包出现后她替男主和学姐预设位置 → 男主依据自己的三条线索追问信息差 → 女主承认恐惧并交出未整理材料 → 当前男主拒绝继承T1答案，在完整知情后重新选择 → 二人以放弃本线证据、计划和当前记忆为代价确认关系。
- **全卷悬疑曲线**：9月8日男主收到但不公开内容的第二句短讯 → 女主对返还节点的异常警觉与男主的边界追问累积 → 10月18日原作包留下双方审核基准 → 11月9日返还包出现并暴露内容替换 → 女主过早行动导致撤链、证据残缺和学姐拒绝 → 男主把提前命名、自己的短讯和学姐质问连成信息差 → 短讯公开、有限跨线事实公开，调查计划仍可执行却被双方主动放弃。
- **甜感与高压比例**：约54%校园／关系／竞赛合作甜感，约46%悬疑／证据／知情权压力。9月8日至11月8日以关系拉扯和专业吸引为主，11月9日集中转入高压。
- **卷级中点**：第25章。10月18日双方完成原始作品包审核并交指导老师校内初审；当前男主以本线判断完成专业选择，女主则在最接近T1默契的时刻继续压住关系确认。
- **11月9日加速段起点**：第29章，四章约1.09万字。
- **卷级高潮**：第29—32章。19:38提前提醒、19:42返还、19:49转发、局部取证、21:36撤链、学姐有限确认与拒绝依次发生；第32章以连续25分钟完成短讯公开、有限公开、替代感冲突、8:30计划、触发后果公开和关系确认。
- **卷末钩子**：两部手机保留次日8:30共同日程，男主正准备继续阅读女主交出的未整理材料；关系确认触发第三次回档，女主抵达T3的9月15日，T2证据、计划和当前男主记忆全部消失。
- **与第一卷的差异化说明**：本卷不重演组队、版本体系建立、岗位撤权、权限变更、拒签、退出校审或原始包交付冲突。男女主始终保留原岗位，主线从T1的行动权推进到知情权；甜感来自当前男主重新作出的专业与关系选择，以及女主记得更多却不能把默契当作继承物的校园拉扯。

- **契约风险**：契约安全。女主保有跨线记忆与提前识别风险的因果权；男主保有知情、上传、等待和当前关系选择的因果权；学姐保有成果确认与使用授权边界。调查计划先独立成立，关系确认不交换职业决定，也不是逃避调查失败。
