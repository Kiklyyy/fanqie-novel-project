## 1. 第一卷总览

- **最终章节数量**：17章。
- **选择理由**：17章可用3章完成2030年开篇的信息阶梯，用11章完成T1的相识重建、专业互认、双向心动及控制升级，再用3章连续承载10月18日高潮。相较更紧的安排，它不会把专业互认与岗位控制挤在同一情绪阶段；相较更松的安排，它不需要拆出只承担转场或重复制作流程的章节。
- **总字数**：约4.07万字，落在3.6万—4.2万字范围内。
- **2030年开篇**：3章，约7200字。
- **T1**：14章，约3.35万字。
- **全卷关系曲线**：2030年失而复得但无法续接旧关系 → T1熟悉感与陌生人格冲突 → 专业互认与双向心动 → 女主以保护为名逐步收紧男主岗位 → 男主拒绝被撤权后继续背书 → 女主先归还职业权限 → 当前两人独立确认感情。
- **全卷悬疑曲线**：历史材料推翻“主动盗用”旧判断 → 共同启动与有限回档规则建立 → 当前男主收到但暂未公开的第一句短讯 → 女主依据T0责任链保护版本 → 保护升级为排除 → 短讯公开证明双方存在严重信息差 → 真心确认意外触发第二次回档。
- **甜感与高压比例**：约55%关系／校园／专业默契，约45%悬疑／流程／权限压力；两者允许同场叠加，不以纯日常章或纯程序章凑比例。
- **卷级中点**：第09章。男女主完成第一次足以看见彼此完整专业价值的阶段成果，双向心动具备可信基础；与此同时，女主开始把“版本必须受保护”转化为“关键岗位必须由自己掌握”。
- **卷级高潮**：第15—17章。权限变更与拒签使职业合作断裂；第一句短讯公开；女主先撤回单人安排并恢复共同管理；职业问题结算后，当前两人再独立确认感情并触发回档。
- **卷末钩子**：女主抵达T2的9月8日，已确认真心关系确认是回档触发行为，却仍不知道它为何被选中，也不知道如何在不冻结感情的情况下继续调查。
- **视角**：全卷统一使用女主第三人称限知，不开放任何其他人物独立视角。
- **契约风险**：契约安全。女主保有调查与跨线信息的因果权；当前男主保有岗位、签字、退出与关系选择的因果权；权限恢复和关系确认分别结算，不以恋爱交换职业决定。
